# 🗺️ Conquer the World - Web Game

En webversjon av det klassiske Roblox-spillet "Conquer the World". Ekspander territoriet ditt og dominerer verden!

## 🎮 Hvordan spille

- **Hevde:** Klikk på tom firkant ved siden av ditt territorium - Kostnad: 50 💰
- **Angripe:** Klikk på fiendtlig territorium - Kostnad: 5 ⚔️
- **Generere ressurser:** Du får +5 💰 og +2 ⚔️ hver 5. sekund
- **Dominere:** Få kontroll over flest ruter og besejr fiendene!

## 🎨 Spillmekanikk

- **5x5 rutenett**: 25 territorier totalt
- **4 spillere**: Du + 3 AI-motstandere
- **Ressurstyper**:
  - 💰 **Cash**: For å hevde nøytrale ruter
  - ⚔️ **Troops**: For å angripe fiendtlig territorium
- **AI-motstandere**: Ekspanderer og angriper automatisk
